# TRADEu Design System

## Purpose

The TRADEu Design System provides the visual foundation for the platform.

## Visual Direction

TRADEu uses a dark, trading-first interface designed for dense market information while maintaining clear hierarchy and readability.

## Core Principles

- Dark-first interface
- High information clarity
- Strong visual hierarchy
- Consistent spacing
- Reusable surfaces and components
- Clear trading status semantics
- Responsive layouts
- Minimal visual noise

## Core Colors

- Background: `#070b14`
- Surface: `#0d1422`
- Elevated Surface: `#111a2b`
- Primary: `#22d3ee`
- Positive: `#34d399`
- Negative: `#f87171`
- Warning: `#fbbf24`
- Information: `#60a5fa`

## Typography

The application uses Geist as the primary interface font and Geist Mono for technical/data-oriented content.

## Surfaces

The design system defines:

- Base background
- Standard surface
- Elevated surface
- Muted surface
- Standard borders
- Strong borders

## Status Semantics

Positive, negative, warning, and informational states use dedicated semantic tokens.

## Component Strategy

Reusable UI components will be developed through `@tradeu/ui`.

The complete application interface is intentionally deferred to Phase 06 — Main UI.
